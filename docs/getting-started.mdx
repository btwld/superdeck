# Getting started

Create a SuperDeck app and build your first presentation.

## Prerequisites

- **Flutter SDK** version 3.38.1 or higher
- Use the Dart SDK bundled with your Flutter installation
- Flutter SDK available on your machine

## Installation

### Install SuperDeck CLI

```bash
dart pub global activate superdeck_cli
```

### Create your project

```bash
superdeck create my_presentation
cd my_presentation
```

This creates a starter Flutter app with:
- Sample `slides.md`
- A preconfigured SuperDeck `main.dart`
- A startup loader in `web/`
- Platform shells for web and desktop/mobile Flutter targets

### Install dependencies

```bash
flutter pub get
```

Generated apps keep the SDK constraint emitted by your installed `flutter create` toolchain.

## Your first presentation

Edit the generated `slides.md` file:

```markdown
---
title: My First Presentation
---

@block

# Welcome to SuperDeck!

This is your first slide.

---
---

@block

## What is SuperDeck?

Create beautiful presentations using:

- Markdown for content
- Flutter for rendering
- Block-based layouts

---
---

## Two-Column Layout

@section

@block
### Left Column
- Point one
- Point two  
- Point three

@block
### Right Column
![Flutter Logo](https://storage.googleapis.com/cms-storage-bucket/4fd5520fe28ebf839174.svg)

---
```

## Build your presentation

```bash
# Build once
dart run superdeck_cli:main build

# Watch for changes (recommended)
dart run superdeck_cli:main build --watch
```

## Run your app

```bash
flutter run
```

## Development workflow

Use two terminals:

**Terminal 1** - Watch mode:
```bash
dart run superdeck_cli:main build --watch
```

**Terminal 2** - Flutter app:
```bash
flutter run
```

Edit `slides.md`, and the CLI rebuilds automatically. Hot reload Flutter to see changes.

## File structure

After creation, your project will have:

```
your-flutter-project/
├── slides.md                 # Your presentation content
├── web/                      # Loader and bootstrap shell
├── .superdeck/
│   ├── superdeck.json        # Generated presentation data
│   ├── assets/               # Generated assets
│   └── generated_assets.json # Asset references
├── pubspec.yaml              # Updated with asset configuration
└── lib/
    └── main.dart             # Your Flutter app
```

## Troubleshooting

**Asset errors during build**
- Verify `pubspec.yaml` includes `.superdeck/` and `.superdeck/assets/`
- If this app was originally created with SuperDeck, run `superdeck create .` to restore the starter slides, README, web loader, and `pubspec.yaml` entries
- `superdeck create .` keeps your app code and platform folders untouched

**SuperDeckApp.initialize() fails**
- Call `WidgetsFlutterBinding.ensureInitialized()` first
- Verify `slides.md` exists and is valid

**Changes not appearing**
- Confirm CLI watch mode is running
- Hot reload Flutter after rebuilds complete
