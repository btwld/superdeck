# Getting started

Set up SuperDeck in your Flutter project and create your first presentation.

## Prerequisites

- **Flutter SDK** version 3.38.1 or higher
- **Dart SDK** version 3.10.0 or higher
- Flutter project (or create one with `flutter create my_presentation`)

## Installation

### Install SuperDeck CLI

```bash
dart pub global activate superdeck_cli
```

### Set up your project

In your Flutter project directory:

```bash
cd your-flutter-project
superdeck setup
```

This creates:
- Sample `slides.md` file
- Asset configuration in `pubspec.yaml`
- macOS entitlements for network access
- Custom `index.html` for web with loading indicator

### Add SuperDeck dependency

```bash
flutter pub add superdeck
```

### Initialize SuperDeck in your app

Update your `main.dart`:

```dart
import 'package:flutter/widgets.dart';
import 'package:superdeck/superdeck.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final runtime = await SuperDeckRuntime.create(
    source: const DeckSource.local(
      slidesPath: 'slides.md',
      watch: true,
    ),
    runtimeConfig: const DeckRuntimeConfig(),
    theme: const DeckTheme(
      debug: true,
    ),
  );

  runApp(
    SuperDeckApp(runtime: runtime),
  );
}
```

## Your first presentation

Edit the generated `slides.md` file:

```markdown
---
title: My First Presentation
---

# Welcome to SuperDeck!

This is your first slide.

---

## What is SuperDeck?

Create beautiful presentations using:

- Markdown for content
- Flutter for rendering
- Block-based layouts

Use `@block` for markdown content blocks.

---

@section

@block
### Left Column
- Point one
- Point two  
- Point three

@block
### Right Column
![Flutter Logo](https://storage.googleapis.com/cms-storage-bucket/4fd5520fe28ebf839174.svg)

---
```

## Run your presentation

```bash
flutter run
```

## Development workflow

Use `DeckSource.local(watch: true)` during development. SuperDeck will:

- build `slides.md` before the first frame
- watch `slides.md` for changes
- rebuild deck artifacts in `.superdeck/`

Run the app with:

```bash
flutter run
```

Edit `slides.md`, and SuperDeck rebuilds automatically. Use Flutter hot reload
for code-side style/widget/template changes.

## File structure

After setup, your project will have:

```
your-flutter-project/
├── slides.md                 # Your presentation content
├── .superdeck/
│   ├── superdeck.v2.json     # Generated presentation data
│   ├── assets/               # Generated assets
│   └── generated_assets.v2.json # Asset references
├── pubspec.yaml              # Updated with asset configuration
└── lib/
    └── main.dart             # Your Flutter app
```

## Troubleshooting

**Asset errors during build**
- Verify `pubspec.yaml` includes `.superdeck/` and `.superdeck/assets/`
- Run `superdeck setup` to fix configuration

**SuperDeckRuntime.create() fails**
- Call `WidgetsFlutterBinding.ensureInitialized()` first
- Verify `slides.md` exists and is valid
- Use `DeckSource.bundle(...)` instead of `DeckSource.local(...)` for bundled/web-only deployments

**Changes not appearing**
- Confirm `DeckSource.local(watch: true)` is enabled
- Hot reload Flutter after code-side changes
