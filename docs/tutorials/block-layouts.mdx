# Block layouts

SuperDeck uses a block-based layout system for flexible content arrangement. Blocks are containers that hold different content types.

## Core concept

Blocks automatically arrange themselves:

- **Vertical stacking** - Blocks stack vertically by default
- **Horizontal sections** - Use `@section` for side-by-side layouts
- **Flexible sizing** - Control space with `flex`

## Common blocks

```markdown
@block        # Markdown content (most common)
@section       # Container for horizontal layouts
@image         # Images with fit options
@dartpad       # Interactive code examples
@qrcode        # QR codes
@widget        # Custom Flutter widgets
```

## Layout examples

### Single column (default)
```markdown
# Title

Regular markdown content flows vertically.

More content below.
```

### Two columns  
```markdown
@section

@block
Left side content

@block  
Right side content
```

### Flexible sizing
```markdown
@section

@block {
  flex: 2
}
Takes 2/3 of the space

@block {
  flex: 1
}
Takes 1/3 of the space
```

### Mixed content
```markdown
@section

@block
## Text Content
- Point one
- Point two

@image {
  src: assets/screenshot.png
  fit: contain
}
```

## Block properties

Content blocks and widgets support these properties. Sections support `flex`
and `align`; set `scrollable` on the child block or widget that overflows.

- **`flex`** - Relative size (default: 1)
- **`align`** - Content alignment (center, topLeft, etc.)
- **`scrollable`** - Enable scrolling (default: false)

```markdown
@block {
  flex: 2
  align: center
  scrollable: true
}
```

## Layout patterns

### Hero section
```markdown
@section

@block {
  align: center
}
# Big Title
## Subtitle
```

### Content + visual
```markdown
@section

@block {
  flex: 2
}
## Feature Description
Detailed explanation...

@block
![Feature Screenshot](image.png)
```

### Three columns
```markdown
@section

@block
### Option A

@block  
### Option B

@block
### Option C
```

## Key takeaways

- Start with `@block` blocks
- Use `@section` for side-by-side layouts
- Control sizing with `flex`
- Mix content types freely
- Layouts adapt to screen size
