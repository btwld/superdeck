# Contracts and schemas

`superdeck_core` is the canonical contract package for `superdeck.json`.

## Root slides contract (`superdeck.json`)

The compiled payload is a raw top-level `List<Slide>`.

Top-level shape:

- JSON array of slide objects
- No root object wrapper
- No root `configuration` payload

## Contract note

This slides array shape is the supported `superdeck.json` contract for current SuperDeck tooling and runtime consumers.

## Machine-readable schema artifacts

Canonical JSON Schema artifacts are exported to:

- `packages/core/schema/superdeck.slides.schema.json`

Commands:

```bash
melos run contracts:export
melos run contracts:check
```
