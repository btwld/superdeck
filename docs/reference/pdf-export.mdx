# PDF export

PDF export lives in the optional `superdeck_pdf` package. The base
`superdeck` package no longer includes PDF export UI or PDF dependencies.

## Optional export package

Add `superdeck_pdf` when an application needs PDF output. The package provides
the PDF export dialog and controller while depending on public SuperDeck slide
rendering and capture APIs.

## Platform notes

The default saver uses `file_saver`: web exports trigger a browser download,
and native exports use the platform save dialog.
