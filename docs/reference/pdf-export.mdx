# PDF export

SuperDeck can export rendered slides to PDF on web and native Flutter targets.

## Built-in export

The presentation bottom bar includes a save button. Selecting it opens the
PDF export dialog automatically, captures the slides, builds the PDF, and
saves it. No setup is required.

## Platform notes

The default saver uses `file_saver`: web exports trigger a browser download,
and native exports use the platform save dialog.
