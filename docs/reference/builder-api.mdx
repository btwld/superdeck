# superdeck_builder API reference

`superdeck_builder` is the build-time engine for SuperDeck presentations.

Most projects should run builds through `superdeck_cli`, for example
`dart run superdeck_cli:main build --watch`. Use `superdeck_builder` directly
when you need programmatic control for custom tooling, editor integrations, or
another build system.

## Imports

```dart
import 'package:superdeck_builder/superdeck_builder.dart';
import 'package:superdeck_core/superdeck_core.dart'
    show DeckBuildStore, DeckWorkspace;
```

`superdeck_builder` exports the builder types. `DeckWorkspace` and
`DeckBuildStore` come from `superdeck_core` and are required by the builder
constructor signatures.

## DeckBuilder

`DeckBuilder` builds decks from Markdown by reading a workspace, parsing slides,
running tasks, writing build artifacts, and returning processed slides.

### Constructor

```dart
DeckBuilder({
  required List<Task> tasks,
  required DeckWorkspace workspace,
  required DeckBuildStore store,
  int concurrentSlides = 4,
});
```

### `tasks`
**Type:** `List<Task>`

Tasks run for each slide, in list order.

```dart
DeckBuilder(
  tasks: [
    DartFormatterTask(),
    AssetGenerationTask.withDefaults(store: store),
  ],
  workspace: workspace,
  store: store,
)
```

### `workspace`
**Type:** `DeckWorkspace`

Workspace paths used to read `slides.md` and write `.superdeck` build output.

```dart
final workspace = DeckWorkspace(
  projectDir: '.',
  slidesPath: 'slides.md',
  outputDir: '.superdeck',
  assetsPath: 'assets',
);
```

### `store`
**Type:** `DeckBuildStore`

Build-side storage used by the builder to initialize files, read Markdown, save
deck references, save build status, and track generated assets.

```dart
final store = DeckBuildStore(workspace: workspace);
```

### `concurrentSlides`
**Type:** `int` | **Default:** `4`

Number of slides processed concurrently in each batch.

## Methods

### `build()`

```dart
Future<Iterable<Slide>> build()
```

Runs one build and returns the processed slides.

During a build, `DeckBuilder`:

1. Initializes the `DeckBuildStore`
2. Saves build status as `DeckBuildPhase.building`
3. Clears generated asset tracking
4. Reads deck Markdown from the store
5. Parses raw slides
6. Runs every task for every slide
7. Saves deck references
8. Saves build status as `DeckBuildPhase.success`

If a task throws an `Exception`, `DeckBuilder` wraps it in `TaskException` and
rethrows it from `build()`.

```dart
final slides = await builder.build();
```

### `watchAndBuild()`

```dart
Stream<BuildEvent> watchAndBuild()
```

Runs an initial build, then watches `workspace.slidesFile` and rebuilds when the
file changes.

The stream emits:

1. `BuildStarted`
2. `BuildCompleted` when the build succeeds
3. `BuildFailed` when the build throws

The stream continues watching for later file changes.

```dart
await for (final event in builder.watchAndBuild()) {
  switch (event) {
    case BuildStarted():
      print('Build started');
    case BuildCompleted(:final slides):
      print('Built ${slides.length} slides');
    case BuildFailed(:final error, :final stackTrace):
      print('Build failed: $error');
      if (stackTrace != null) {
        print(stackTrace);
      }
  }
}
```

### `dispose()`

```dart
Future<void> dispose()
```

Disposes every task in `tasks`.

Call `dispose()` when you are done with the builder, especially after ending
watch mode.

```dart
await builder.dispose();
```

## StandardDeckBuildPipeline

`StandardDeckBuildPipeline` is the supported entry point for the default
SuperDeck build pipeline.

### `create(...)`

```dart
static DeckBuilder create({
  required DeckWorkspace workspace,
  required DeckBuildStore store,
  int concurrentSlides = 4,
})
```

Creates a `DeckBuilder` with the standard tasks in this order:

1. `DartFormatterTask()`
2. `AssetGenerationTask.withDefaults(...)`

```dart
final builder = StandardDeckBuildPipeline.create(
  workspace: workspace,
  store: store,
);
```

`StandardDeckBuildPipeline.create` does not accept a custom task list. To add,
remove, or reorder tasks, construct `DeckBuilder` directly.

```dart
final builder = DeckBuilder(
  tasks: [
    MyTask(),
    DartFormatterTask(),
    AssetGenerationTask.withDefaults(store: store),
  ],
  workspace: workspace,
  store: store,
);
```

## Task

`Task` is the base class for slide processing work.

```dart
abstract base class Task {
  Task(this.name);

  final String name;

  FutureOr<void> run(context);

  FutureOr<void> dispose();
}
```

### `name`
**Type:** `String`

Task name used for logging and failure identification.

### `run(context)`
**Type:** `FutureOr<void>`

Runs the task for one slide.

Tasks can update the slide content by calling `context.updateSlide(...)`.
Built-in tasks use this pattern after processing slide Markdown.

### `dispose()`
**Type:** `FutureOr<void>` | **Default:** no-op

Override `dispose()` when a task owns resources that need explicit cleanup.

### Custom task example

```dart
import 'dart:async';

import 'package:superdeck_builder/superdeck_builder.dart';

final class StripSpeakerNotesTask extends Task {
  StripSpeakerNotesTask() : super('strip_speaker_notes');

  @override
  FutureOr<void> run(dynamic context) {
    final content = context.slide.content as String;
    final updatedContent = content.replaceAll(
      RegExp(r'<!-- speaker:.*?-->', dotAll: true),
      '',
    );

    context.updateSlide(
      context.slide.copyWith(content: updatedContent),
    );
  }

  @override
  FutureOr<void> dispose() {}
}
```

Plug the task into a custom `DeckBuilder` task list:

```dart
final builder = DeckBuilder(
  tasks: [
    StripSpeakerNotesTask(),
    DartFormatterTask(),
    AssetGenerationTask.withDefaults(store: store),
  ],
  workspace: workspace,
  store: store,
);
```

## Built-in tasks

### `AssetGenerationTask`

Processes build-time assets in slide content through an asset generation
pipeline, then updates the slide content with generated asset references.

Use `AssetGenerationTask.withDefaults` for the standard asset pipeline.

```dart
factory AssetGenerationTask.withDefaults({
  required DeckBuildStore store,
  AssetCacheStore? cacheStore,
})
```

The default generator list is empty; consumers register their own generators
by constructing `AssetGenerationTask` directly.

```dart
AssetGenerationTask.withDefaults(store: store)
```

### `DartFormatterTask`

Formats fenced Dart code blocks in slide Markdown.

```dart
DartFormatterTask({
  Map<String, String>? environmentOverrides,
  int? lineLength,
  bool fix = true,
})
```

The task processes fenced code blocks where the language is `dart`. If
formatting a block fails, it logs the error and skips that block.

```dart
DartFormatterTask(
  lineLength: 80,
  fix: true,
)
```

## Build events

`BuildEvent` is the sealed base type for events emitted by `watchAndBuild()`.

### `BuildStarted`

```dart
const BuildStarted()
```

Emitted before each build starts.

### `BuildCompleted`

```dart
const BuildCompleted(List<Slide> slides)
```

Emitted when a build completes successfully.

### `BuildFailed`

```dart
const BuildFailed(Object error, [StackTrace? stackTrace])
```

Emitted when a watched build fails. `DeckBuilder` also saves failure status to
the build store before emitting this event.

## Errors

### `TaskException`

```dart
const TaskException(
  String taskName,
  Exception originalException,
  int slideIndex,
)
```

Raised by `DeckBuilder` when a task throws an `Exception`.

Properties:

### `taskName`
**Type:** `String`

Name of the task that failed.

### `originalException`
**Type:** `Exception`

Original exception thrown by the task.

### `slideIndex`
**Type:** `int`

Zero-based slide index being processed when the task failed.

When using `build()`, the `TaskException` is thrown to the caller. When using
`watchAndBuild()`, the same error is surfaced as `BuildFailed.error`.

### `DeckFormatException`

```dart
const DeckFormatException(
  String message,
  dynamic source,
  int offset,
)
```

`DeckFormatException` extends `FormatException` and is re-exported by
`superdeck_builder`.

## Minimal example

```dart
import 'package:superdeck_builder/superdeck_builder.dart';
import 'package:superdeck_core/superdeck_core.dart'
    show DeckBuildStore, DeckWorkspace;

Future<void> main() async {
  final workspace = DeckWorkspace();
  final store = DeckBuildStore(workspace: workspace);
  final builder = StandardDeckBuildPipeline.create(
    workspace: workspace,
    store: store,
  );

  try {
    final slides = await builder.build();
    print('Built ${slides.length} slides');

    await for (final event in builder.watchAndBuild()) {
      switch (event) {
        case BuildStarted():
          print('Build started');
        case BuildCompleted(:final slides):
          print('Built ${slides.length} slides');
        case BuildFailed(:final error, :final stackTrace):
          print('Build failed: $error');
          if (stackTrace != null) {
            print(stackTrace);
          }
      }
    }
  } finally {
    await builder.dispose();
  }
}
```
