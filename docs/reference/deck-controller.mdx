# DeckController reference

`DeckController` is the composition root for deck state. It exposes two state objects:

- `session` — load/build lifecycle
- `presentation` — routing, navigation, menu, notes, thumbnails

Consumers reach through those. `DeckController` itself only owns `options` and the cross-cutting `slides` computed.

## Obtaining a controller

### `DeckController.of(BuildContext context)`

```dart
import 'package:flutter/widgets.dart';
import 'package:superdeck/superdeck.dart';

Widget build(BuildContext context) {
  final deck = DeckController.of(context);
  return Text('${deck.presentation.totalSlides.value} slides');
}
```

For reactive UI, read signal values inside `Watch` from `signals_flutter`.

```dart
import 'package:flutter/widgets.dart';
import 'package:signals_flutter/signals_flutter.dart';
import 'package:superdeck/superdeck.dart';

Widget build(BuildContext context) {
  return Watch((context) {
    final deck = DeckController.of(context);
    return Text('Slide ${deck.presentation.currentIndex.value + 1}');
  });
}
```

## Top-level surface

### `slides`
**Type:** `ReadonlySignal<List<SlideConfiguration>>`

Configured slides built from the loaded slide data and the current `DeckOptions`. Empty while loading or when a fatal error has prevented any load.

### `options`
**Type:** `Signal<DeckOptions>`

Writable. Assigning a new value recomputes `slides`. Managed automatically by `SuperDeckApp` through `DeckControllerBuilder`; application code should mutate `SuperDeckApp.options`, not this signal.

### `session`
**Type:** `DeckSessionState`

Load/build lifecycle. See [Session state](#session-state).

### `presentation`
**Type:** `DeckPresentationState`

Routing, navigation, UI panels, thumbnails. See [Presentation state](#presentation-state).

### `reloadDeck()`
**Type:** `Future<void> Function()`

Asks the underlying `DeckLoader` to reload.

### `dispose()`
Tears down both state classes, the `options` signal, and the `slides` computed.

## Session state

`deck.session` exposes the load/build lifecycle.

| Member | Type | Notes |
|---|---|---|
| `loadedSlides` | `ReadonlySignal<List<Slide>?>` | Raw slides from the loader; `null` until first successful load |
| `isLoading` | `ReadonlySignal<bool>` | `true` while the loader is running |
| `error` | `ReadonlySignal<Object?>` | Fatal load error when no slides have ever loaded |
| `hasFatalError` | `ReadonlySignal<bool>` | `true` when `error != null && loadedSlides == null` |
| `isBuildActive` | `ReadonlySignal<bool>` | `true` during a rebuild cycle |
| `buildFailure` | `ReadonlySignal<DeckBuildError?>` | Rebuild failure after a successful prior load (non-fatal) |
| `reload()` | `Future<void> Function()` | Re-trigger the loader |

Fatal-vs-build distinction: if the app has never loaded slides, any failure is `error` / `hasFatalError`. If the app has loaded before and a subsequent rebuild fails, the prior snapshot stays on screen and `buildFailure` is populated instead.

```dart
Widget build(BuildContext context) {
  final session = DeckController.of(context).session;
  return Watch((context) {
    if (session.hasFatalError.value) {
      return Text('Load failed: ${session.error.value}');
    }
    if (session.isBuildActive.value) return const Text('Rebuilding…');
    final buildFailure = session.buildFailure.value;
    if (buildFailure != null) return Text('Build failed: ${buildFailure.message}');
    return const SizedBox.shrink();
  });
}
```

## Presentation state

`deck.presentation` exposes routing, navigation, UI panel state, and thumbnails.

### Signals

| Member | Type | Notes |
|---|---|---|
| `router` | `GoRouter` | The internal router. Pass to `MaterialApp.router` via `SuperDeckApp`. |
| `currentIndex` | `ReadonlySignal<int>` | Active slide index, clamped to valid range |
| `totalSlides` | `ReadonlySignal<int>` | Current slide count |
| `currentSlide` | `ReadonlySignal<SlideConfiguration?>` | Slide at `currentIndex`, or `null` if slides empty |
| `canGoNext` | `ReadonlySignal<bool>` | `currentIndex < totalSlides - 1` |
| `canGoPrevious` | `ReadonlySignal<bool>` | `currentIndex > 0` |
| `isTransitioning` | `ReadonlySignal<bool>` | `true` during the post-`goToSlide` transition window |
| `isMenuOpen` | `ReadonlySignal<bool>` | Slide-menu panel visibility |
| `isNotesOpen` | `ReadonlySignal<bool>` | Notes panel visibility |

### Methods

| Member | Signature | Notes |
|---|---|---|
| `goToSlide` | `Future<void> Function(int index)` | Clamp-checked; no-op if out of range |
| `nextSlide` | `Future<void> Function()` | No-op when `!canGoNext.value` |
| `previousSlide` | `Future<void> Function()` | No-op when `!canGoPrevious.value` |
| `openMenu` | `void Function()` | Sets `isMenuOpen` to `true` |
| `closeMenu` | `void Function()` | Sets `isMenuOpen` to `false` |
| `toggleNotes` | `void Function()` | Toggles `isNotesOpen` |
| `generateThumbnails` | `void Function(BuildContext, List<SlideConfiguration>, {bool force})` | Reconciles the thumbnail cache (disposes stale entries) and kicks off background generation. Pass `deck.slides.value` for the current slide set. |
| `getThumbnail` | `AsyncThumbnail? Function(String slideKey)` | `null` until thumbnail generation produces one |

```dart
Widget buildNavBar(BuildContext context) {
  final pres = DeckController.of(context).presentation;
  return Watch((context) {
    return Row(children: [
      IconButton(
        onPressed: pres.canGoPrevious.value ? pres.previousSlide : null,
        icon: const Icon(Icons.arrow_back),
      ),
      Text('${pres.currentIndex.value + 1} / ${pres.totalSlides.value}'),
      IconButton(
        onPressed: pres.canGoNext.value ? pres.nextSlide : null,
        icon: const Icon(Icons.arrow_forward),
      ),
    ]);
  });
}
```

## Lifecycle note

`DeckController` is owned by `DeckControllerBuilder` inside `SuperDeckApp`. Application code normally never constructs or disposes a controller directly — it only reads through `DeckController.of(context)`. If you build a custom host, call `dispose()` when you tear the widget tree down.
