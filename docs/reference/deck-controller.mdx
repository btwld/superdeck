# DeckController reference

`DeckController` is the unified facade for deck state and operations. It combines loaded slide state, build lifecycle, routing, navigation, menu and notes state, and thumbnail access behind one controller.

## Obtaining a controller

### `DeckController.of(BuildContext context)`
**Type:** `DeckController Function(BuildContext context)`

In regular apps, get the controller from inside the `SuperDeckApp` widget tree:

```dart
import 'package:flutter/widgets.dart';
import 'package:superdeck/superdeck.dart';

Widget build(BuildContext context) {
  final deck = DeckController.of(context);
  return Text('${deck.totalSlides.value} slides');
}
```

For reactive UI, read signal values inside `Watch` from `signals_flutter`.

```dart
import 'package:flutter/widgets.dart';
import 'package:signals_flutter/signals_flutter.dart';
import 'package:superdeck/superdeck.dart';

Widget build(BuildContext context) {
  return Watch((context) {
    final deck = DeckController.of(context);
    return Text('Slide ${deck.currentIndex.value + 1}');
  });
}
```

## Reactive state signals

All state accessors return `ReadonlySignal<T>`. Read `.value` inside `Watch((context) { ... })` so Flutter rebuilds when the signal changes.

### `slides`
**Type:** `ReadonlySignal<List<SlideConfiguration>>`

Configured slides built from the loaded slide data and current `DeckOptions`.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text('${deck.slides.value.length} configured slides');
});
```

### `totalSlides`
**Type:** `ReadonlySignal<int>`

The number of configured slides.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text('${deck.totalSlides.value} total slides');
});
```

### `currentIndex`
**Type:** `ReadonlySignal<int>`

The zero-based index of the active slide.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text('Slide ${deck.currentIndex.value + 1}');
});
```

### `currentSlide`
**Type:** `ReadonlySignal<SlideConfiguration?>`

The active slide configuration, or `null` when no slide is available.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  final slide = deck.currentSlide.value;
  return Text(slide?.key ?? 'No slide');
});
```

### `canGoNext`
**Type:** `ReadonlySignal<bool>`

Whether there is a slide after the current slide.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.canGoNext.value ? 'Next available' : 'Last slide');
});
```

### `canGoPrevious`
**Type:** `ReadonlySignal<bool>`

Whether there is a slide before the current slide.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.canGoPrevious.value ? 'Previous available' : 'First slide');
});
```

### `isLoading`
**Type:** `ReadonlySignal<bool>`

Whether the deck loader is currently loading or reloading slides.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.isLoading.value ? 'Loading' : 'Ready');
});
```

### `hasError`
**Type:** `ReadonlySignal<bool>`

Whether the initial deck load has a fatal error and no slides are available.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.hasError.value ? 'Load failed' : 'No fatal error');
});
```

### `error`
**Type:** `ReadonlySignal<Object?>`

The fatal initial-load error object, or `null` when there is no fatal error.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.error.value?.toString() ?? 'No error');
});
```

### `isBuildActive`
**Type:** `ReadonlySignal<bool>`

Whether a deck rebuild is currently in progress.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.isBuildActive.value ? 'Building' : 'Build idle');
});
```

### `buildFailure`
**Type:** `ReadonlySignal<DeckBuildError?>`

The latest non-fatal rebuild failure after slides have loaded, or `null`.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  final failure = deck.buildFailure.value;
  return Text(failure?.message ?? 'No build failure');
});
```

### `isMenuOpen`
**Type:** `ReadonlySignal<bool>`

Whether the slide menu is open.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.isMenuOpen.value ? 'Menu open' : 'Menu closed');
});
```

### `isNotesOpen`
**Type:** `ReadonlySignal<bool>`

Whether the notes panel is open.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.isNotesOpen.value ? 'Notes open' : 'Notes closed');
});
```

### `isTransitioning`
**Type:** `ReadonlySignal<bool>`

Whether a slide transition is currently active.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  return Text(deck.isTransitioning.value ? 'Transitioning' : 'Still');
});
```

## Navigation

The sections below list the navigation methods on `DeckController`. For
user-facing navigation semantics — keyboard shortcuts, touch gestures,
deep-link URLs, and index-bound behavior — see the
[Navigation reference](./navigation.mdx).

### `goToSlide(int index)`
**Type:** `Future<void> Function(int index)`

Navigates to a zero-based slide index. Out-of-range indexes are ignored.

```dart
final deck = DeckController.of(context);
deck.goToSlide(0);
```

### `nextSlide()`
**Type:** `Future<void> Function()`

Navigates to the next slide when `canGoNext.value` is `true`.

```dart
final deck = DeckController.of(context);
deck.nextSlide();
```

### `previousSlide()`
**Type:** `Future<void> Function()`

Navigates to the previous slide when `canGoPrevious.value` is `true`.

```dart
final deck = DeckController.of(context);
deck.previousSlide();
```

### `reloadDeck()`
**Type:** `Future<void> Function()`

Reloads the deck through the active deck loader. This clears fatal errors and build failures before starting the reload.

```dart
final deck = DeckController.of(context);
deck.reloadDeck();
```

## Menu and notes

### `openMenu()`
**Type:** `void Function()`

Opens the slide menu.

```dart
final deck = DeckController.of(context);
deck.openMenu();
```

### `closeMenu()`
**Type:** `void Function()`

Closes the slide menu.

```dart
final deck = DeckController.of(context);
deck.closeMenu();
```

### `toggleNotes()`
**Type:** `void Function()`

Toggles the notes panel.

```dart
final deck = DeckController.of(context);
deck.toggleNotes();
```

## Thumbnails

### `generateThumbnails(BuildContext context, {bool force = false})`
**Type:** `void Function(BuildContext context, {bool force})`

Starts thumbnail generation for the currently configured slides. When `force` is `true`, thumbnails are regenerated instead of reusing cached results.

```dart
final deck = DeckController.of(context);
deck.generateThumbnails(context, force: true);
```

### `getThumbnail(String slideKey)`
**Type:** `AsyncThumbnail? Function(String slideKey)`

Returns the cached asynchronous thumbnail for a slide key, or `null` before a thumbnail has been created.

```dart
Watch((context) {
  final deck = DeckController.of(context);
  final slide = deck.currentSlide.value;
  final thumbnail = slide == null ? null : deck.getThumbnail(slide.key);

  return thumbnail?.build(context) ?? const SizedBox.shrink();
});
```

## Router access

### `router`
**Type:** `GoRouter`

The `GoRouter` instance used by `SuperDeckApp`. The router redirects `/` to `/slides/0` and serves slide pages at `/slides/:index`.

```dart
final deck = DeckController.of(context);
deck.router.go('/slides/0');
```

## Options update

### `updateOptions(DeckOptions newOptions)`
**Type:** `void Function(DeckOptions newOptions)`

`updateOptions` is marked `@internal`. It swaps runtime options and causes the computed `slides` signal to rebuild slide configurations with the new `DeckOptions`.

This is intended for `DeckControllerBuilder`, which calls it when the `SuperDeckApp.options` value changes. Application code should update `SuperDeckApp.options` instead of calling `updateOptions` directly.

## Internal navigation events

### `handleNavigationEvent(NavigationEvent event)`
**Type:** `Future<void> Function(NavigationEvent event)`

`handleNavigationEvent` is marked `@internal`. It maps input events to slide navigation:

1. `NextSlideEvent` calls `goToSlide(currentIndex.value + 1)`
2. `PreviousSlideEvent` calls `goToSlide(currentIndex.value - 1)`
3. `GoToSlideEvent` calls `goToSlide(index)`

These event types are used by SuperDeck input handlers. User code should call `nextSlide`, `previousSlide`, or `goToSlide` directly.

## Lifecycle

`DeckController` is created by `DeckControllerBuilder` inside `SuperDeckApp`. `SuperDeckApp` passes the controller's `router` to `MaterialApp.router`, and `DeckControllerBuilder` provides the controller to descendants through inherited widget state.

Users typically do not construct `DeckController` directly. The public constructor exists for framework integration and takes `deckLoader`, `options`, optional `thumbnailService`, optional `assetCacheStore`, and `transitionDuration`, which defaults to one second.

### `dispose()`
**Type:** `void Function()`

`dispose` is the internal cleanup contract. `DeckControllerBuilder` calls it automatically when the SuperDeck widget tree is removed.

Do not dispose a controller obtained from `DeckController.of(context)`.

## End-to-end example

This widget reads the current slide reactively and jumps to the last slide when pressed.

```dart
import 'package:flutter/material.dart';
import 'package:signals_flutter/signals_flutter.dart';
import 'package:superdeck/superdeck.dart';

class GoToLastSlideButton extends StatelessWidget {
  const GoToLastSlideButton({super.key});

  @override
  Widget build(BuildContext context) {
    final deck = DeckController.of(context);

    return Watch((context) {
      final currentSlide = deck.currentSlide.value;
      final lastIndex = deck.totalSlides.value - 1;
      final isOnLastSlide =
          currentSlide != null && currentSlide.slideIndex == lastIndex;

      return TextButton(
        onPressed: lastIndex >= 0 && !isOnLastSlide
            ? () {
                deck.goToSlide(lastIndex);
              }
            : null,
        child: Text(isOnLastSlide ? 'On last slide' : 'Go to last slide'),
      );
    });
  }
}
```
